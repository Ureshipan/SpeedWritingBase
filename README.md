# Тренажёр скоростной печати - Московские улицы

Веб-приложение для тренировки скоростной печати с тематикой московских улиц. Игрок управляет машинкой, которая движется по дороге, и должен быстро и без ошибок печатать названия улиц.

## Особенности

- 🚗 Визуализация движения машинки по дороге
- 🏁 Система жизней - ошибки приводят к авариям
- 📊 Отслеживание статистики (счёт, точность, количество слов)
- 💾 Сохранение результатов на сервере
- 🎯 Динамическая сложность - длина улиц увеличивается с прогрессом
- 📱 Адаптивный дизайн

## Технологии

- **Backend**: Python, Flask, SQLAlchemy
- **Frontend**: HTML, CSS, JavaScript
- **База данных**: SQLite

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## API Endpoints

### GET `/api/street?length=<длина>`
Получить случайную улицу заданной длины.

**Параметры:**
- `length` (обязательный) - желаемая длина названия улицы

**Ответ:**
```json
{
  "id": 1,
  "name": "Тверская",
  "length": 8
}
```

### POST `/api/result`
Сохранить результат игры.

**Тело запроса:**
```json
{
  "score": 1000,
  "accuracy": 95.5,
  "words_typed": 10,
  "mistakes": 5,
  "time_spent": 120.5,
  "user_id": null
}
```

### GET `/api/results?user_id=<id>&limit=<лимит>`
Получить результаты игр (для будущего использования).

## Игровая механика

1. Нажмите "Начать заезд" для начала игры
2. Появляется название московской улицы
3. Быстро и без ошибок введите название улицы
4. При правильном вводе машинка продвигается вперёд, вы получаете очки
5. При ошибке машинка теряет жизнь (авария) и откатывается назад
6. Игра заканчивается, когда жизни заканчиваются
7. Результаты автоматически сохраняются на сервере
